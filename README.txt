Six's Brother Foundation — Starter Web App

HOW TO USE
1. Open index.html in a modern web browser (Chrome recommended).
2. Use the navigation tabs to add members, tasks, meetings, attendance, decisions, finance, notices, and activity reports.
3. Data is saved in that browser on that device using localStorage.
4. Use "ডেটা ডাউনলোড / Export data" to back up a JSON file and "ডেটা ইমপোর্ট / Import data" to restore it.

IMPORTANT LIMITATION
This is a working local prototype, not a hosted multi-user web app. The data does NOT automatically sync between different users/devices and there is no account/login/security server. Do not store sensitive financial or personal information until a shared database, authentication, access control, and hosting are configured.
For shared use by all members, the next step is deploying a cloud-backed version (e.g. AppSheet with Google Sheets, or a hosted app with database/authentication).
